# Use SpatialRuntime as a blocking external CI gate

## Why opt in?

A conformance decision has three states: **PASS**, **UNRESOLVED** and **FAIL**. An unresolved result is **not approval**. By default, the composite Action may exit successfully for UNRESOLVED so diagnostics can be retained without blocking research CI. If a project uses the result to gate a release, it must opt in to **PASS only**.

## Minimal blocking check

Paste this in your **own repository**, use the immutable merged commit of PR #98 (`76407b7a29e552dd4d5d2ede8c29b6065d4fb0d1`) as shown below, and supply actual evidence under your ownership:

```yaml
name: Verify agent decision-to-execution binding
on: [pull_request]
permissions:
  contents: read
jobs:
  evidence-gate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.12'
      - name: Require grounded decision-to-execution proof
        id: verify
        uses: hippoley/SpatialRuntime/interop/conformance@76407b7a29e552dd4d5d2ede8c29b6065d4fb0d1
        with:
          mode: decision-execution-binding
          file: evidence/decision-execution.json
          require_result: PASS
          report_path: artifacts/decision-execution-review.json
      - name: Retain binding review JSON even if gate rejects a release
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: decision-execution-review
          path: artifacts/decision-execution-review.json
          if-no-files-found: error
```

The evidence file must be generated by your own runtime. Do **not** copy SpatialRuntime's passing fixture to claim your runtime conforms. The uploaded JSON contains the complete PASS/UNRESOLVED/FAIL assessment and explicit scope limits; treat it as review evidence, **not** independent confirmation of external effects. Ensure your report does not contain secrets or private data before uploading artifacts.

| Verification output | Default Action exit | With `require_result: PASS` |
| --- | --- | --- |
| PASS | 0 | 0 |
| UNRESOLVED | 0 | nonzero |
| FAIL | nonzero | nonzero |
| Unsupported `require_result` | N/A | nonzero |

The real composite Action's three-way behavior and invalid configuration are exercised by [`conformance-consumer-gate.yml`](../../../.github/workflows/conformance-consumer-gate.yml).

## Reference-only bundle must never clear a business release gate

`effect-evidence-bundle` with no `adapter_command` runs SpatialRuntime's **own reference evaluator** against its own vectors. Its `PASS` is a smoke-test result, not a statement about the calling runtime.

When `require_result: PASS` is selected, the Action now fails closed if `mode: effect-evidence-bundle` has no `adapter_command`; it emits `conformance_result=UNRESOLVED` and returns nonzero. The default nonblocking reference smoke remains unchanged for existing callers.

For actual customer evidence, either use `decision-execution-binding` with your runtime-owned evidence file, or supply a genuine, runtime-owned adapter using the established `effect-evidence-adapter.v0.1` protocol. The Action cannot authenticate the adapter solely from a command string; inspect and review its actual provenance separately.

**Pinning:** the example above pins PR #98's merged commit (`76407b7a29e552dd4d5d2ede8c29b6065d4fb0d1`), which includes the opt-in PASS-only gate, reference-only bundle guard and durable decision-binding JSON output. PR #93 (`a62e595314f83cd359bbf6a8923b585d0449a41e`) has the first two features but not durable binding receipts. The earlier PR #91 (`d1951faad027fc55264759376980272788d4f874`) lacks the reference-only guard.

## Assurance limits

- PASS is a consistency check **over the supplied evidence**, not independently observed real-world effects.
- A successful GitHub job in your repo does not by itself imply independent signoff of underlying runtime claims.
- Pin to an immutable SHA. The older `conformance-v0.1.0` tag does **not** include this added input.
- Using this in a third-party repository should be separately recorded as externally consumed **only after** independently inspecting its real run and production of evidence. An example in this repository, including this one, is never an adoption event.
